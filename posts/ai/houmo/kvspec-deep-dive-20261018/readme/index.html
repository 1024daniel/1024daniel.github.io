    校验脚本只用 Python 标准库，不导入模型框架。已在本目录通过 uv 创建的 .venv 中运行：

    cd /home/daniel/code/houmo/ai/kvspec-deep-dive-20261018
env PYTHONDONTWRITEBYTECODE=1 \
    TMPDIR="$PWD/tmp" TMP="$PWD/tmp" TEMP="$PWD/tmp" \
    XDG_CACHE_HOME="$PWD/.cache" \
    .venv/bin/python scripts/validate_document.py

    图 8 已使用 Inkscape 1.4.3 从 SVG 渲染为 1800×1480 PNG，并检查中文与布局。重建图形时在本目录执行：

    env PYTHONDONTWRITEBYTECODE=1 TMPDIR="$PWD/tmp" \
    XDG_CACHE_HOME="$PWD/.cache" \
    .venv/bin/python scripts/draw_input_contract.py
env TMPDIR="$PWD/tmp" TMP="$PWD/tmp" TEMP="$PWD/tmp" \
    XDG_CACHE_HOME="$PWD/.cache" XDG_CONFIG_HOME="$PWD/.config" \
    XDG_DATA_HOME="$PWD/.local/share" INKSCAPE_PROFILE_DIR="$PWD/.config/inkscape" \
    inkscape assets/input-name-contract.svg --export-type=png \
    --export-filename=assets/input-name-contract.png

    检查通过不代表完成设备验证：未执行模型导出、编译、GPU/NPU/TCIM 推理、性能测试；其余 Mermaid 图未实际渲染。已人工核对图意和代码关系，脚本检查 fence、图号、声明类型、锚点、本地链接、选定代码摘录、图片文件和数值例。网络来源由阅读时核实，脚本不检查在线 URL。若将主文放到网站内容目录，需要一起同步 assets/，并确保站点能访问相对图片路径。
