    这篇文章是我的 LeetCode 刷题总入口。它不按题号堆积答案，而是按“如何识别模型”组织：看到什么信号，选择什么数据结构，如何验证复杂度。

    如何分类

    一道题可以有多个标签，但只选一个“主模型”归档。主模型由解题时最关键的决策决定，而不是由题目表面出现的数据结构决定。

    主分类常见信号核心问题
    数组与哈希查找、去重、配对能否用空间换时间？
    双指针有序、原地修改、两端移动哪个指针在什么条件下移动？
    滑动窗口连续子数组或子串、最长或最短窗口何时扩张和收缩？
    二分查找有序、单调、最小可行值答案空间是否具有单调性？
    栈与单调栈匹配、下一个更大或更小栈中保持什么不变量？
    链表翻转、环、倒数位置指针更新后是否丢失节点？
    树与图层级、路径、连通、依赖状态应放在哪里？
    回溯所有组合、排列、切分方案选择、结束和撤销条件是什么？
    贪心局部选择、区间调度如何证明局部最优导出全局最优？
    动态规划最优值、方案数、可行性状态、转移、初始化和遍历顺序是什么？

    每道题只记六件事

    1. 题目信号：哪些关键词促使我选择这个模型。
    2. 首次思路：当时怎么想，哪里卡住或走了弯路。
    3. 核心不变量：算法运行过程中始终为真的条件。
    4. 复杂度：时间、空间以及能否继续优化。
    5. 错误点：边界、索引、初始化、语言 API 或思路错误。
    6. 迁移题：两道使用同一模型的题，用来检验是否真正掌握。

    复习规则

    • 首次 AC 后在 1 / 3 / 7 / 14 / 30 天各复习一次。
    • 不先看代码，先用一句话说出模型和不变量。
    • 15 分钟内无法独立完成，就重新标记为待复习。
    • 同一模型连续做 3 道后穿插 1 道旧题，避免依赖上下文猜模板。

    仓库约定

    • 题解文章：content/posts/leetcode-题号-slug.md

    • 题解模板：archetypes/leetcode.md

    • 分类列表维护在 assets/config/leetcode.toml，题解通过 tags 自动进入对应分类。
